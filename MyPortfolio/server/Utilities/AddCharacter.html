1) slice name convention: collisionType + number e.g. blockCollision1,
    blockCollision2... 
    
    for default collision, set the slice name to
    defaultCollision 

    2) write slice data in JSON format: e.g.
    {"collisionType": "blockCollision", "target":"enemy"} 
    
    current available properties: collisionType, target 
    also, collision active is set to true by default

    3) REMEMBER to click on the slice bounding box in
    aseprite if you wish to add it in the current frame, otherwise it won't add
    into the current frame. 

    4) REMEMBER to change the type from Hash to Array
    before exporting. 
    
    Prefer to do: change the export png and json name to
    something understandable. Extra: it is optional to trim the cells before
    exporting but remember to add some padding if the sprite sheet gets too
    close. 

    5) To add defaultImage (used for something like character icon and etc), simply create a folder named defaultImage under character folder 
    and name the image as defaultImage.png
    
    Limitation: currently can only add one animation at a time, to add other animation, retain
    all other info while changing the animation name and its json file path.
